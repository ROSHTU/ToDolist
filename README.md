# Task Manager To-Do List Web App

## Overview

This Task Manager To-Do List Web App is a simple yet powerful tool to help you organize your daily tasks. Built using HTML, CSS, and JavaScript, the app provides a user-friendly interface where you can manage your tasks efficiently. With features like color-based sorting, priority assignment, and a dark mode option, this app enhances your productivity and ensures you stay on top of your tasks.

## Key Features

- **Color-Based Sorting:** Easily categorize your tasks with color coding. Tasks can be sorted based on their assigned colors, allowing for quick visual identification of task categories.
- **Priority Assignment and Sorting:** Assign priorities to your tasks, and sort them accordingly. This feature helps you focus on what matters most by organizing tasks based on their urgency or importance.
- **Dark Mode:** Switch to dark mode for a more comfortable viewing experience, especially in low-light environments. This feature reduces eye strain and adds a modern touch to the app's design.

## Usage

- **Add Tasks:** Enter your task in the input field and press the "Add" button. The task will appear in your task list.
- **Assign Color:** Choose a color for your task to categorize it.
- **Set Priority:** Assign a priority level to your task (e.g., High, Medium, Low).
- **Sort Tasks:** Use the sorting options to organize tasks by color or priority.
- **Dark Mode:** Toggle the dark mode option to switch between light and dark themes.
